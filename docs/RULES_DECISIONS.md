# Rules and design decisions

One line per interpretation, ambiguity or house choice. Status: **verified** (rulebook page
cited), **house** (rulebook silent; our choice), **open** (awaiting owner), **decided** (owner or
engineering choice).

## Rules

| Id    | Topic                              | Decision                                                                                                                                                                | Source                                      | Status   |
| ----- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | -------- |
| D-001 | Starting decks                     | Rouleur 3×{3,4,5,6,7}; sprinteur 3×{2,3,4,5,9}                                                                                                                          | B1                                          | verified |
| D-002 | Exhaustion value                   | 2; separate rouleur and sprinteur supplies                                                                                                                              | B2, B3                                      | verified |
| D-003 | Exhaustion supply                  | Unlimited (`exhaustionSupply: null`)                                                                                                                                    | rulebooks silent                            | house    |
| D-004 | Value modifier order               | Minimums, then crash −2, then ascent cap                                                                                                                                | M2, G12                                     | verified |
| D-005 | Ascent trigger                     | Cap if the move starts on, enters or crosses an ascent; if only step 6+ would enter it, stop before it                                                                  | B4                                          | verified |
| D-006 | Finish tie-break                   | Lower lane (rightmost) wins                                                                                                                                             | B1, B3                                      | verified |
| D-007 | Base-game start order              | Random first placer, then clockwise                                                                                                                                     | B2 (replaces bike tie-breaker)              | decided  |
| D-008 | Dummy teams in tours               | Allowed as non-scoring pace riders                                                                                                                                      | rulebooks silent                            | open     |
| D-009 | Handicap                           | Base rule: +1 exhaustion per deck (+2 very experienced); room option                                                                                                    | B4                                          | verified |
| D-010 | Empty deck                         | No cards at all: play an exhaustion card from the supply                                                                                                                | rulebooks silent                            | house    |
| D-011 | Narrowing slipstream               | Riders move in lane order until full; the rest stay and shift right; riders behind stay                                                                                 | P1                                          | verified |
| D-012 | Breakaway tile side                | White for 5–6 players, black for 1–4 (and for 7–12)                                                                                                                     | P2, P4                                      | verified |
| D-013 | Weather placement                  | Every straight-shaped tile except start and finish, Peloton straights included                                                                                          | M1 (literal reading)                        | house    |
| D-014 | Wet / sharp corner crash           | Only the blocked rider crashes; full-crashed squares are impassable                                                                                                     | M2, G9                                      | verified |
| D-015 | Crashed rider exhaustion           | Normal exhaustion rules apply                                                                                                                                           | rulebooks silent                            | house    |
| D-016 | Tour finish timing                 | Applies at the end of every round with finishers, not only the first                                                                                                    | G4                                          | verified |
| D-017 | Timing strip values                | Flat face: +0:40, +0:30, +0:20, +0:10, +0:00 from the line outwards; ascent face: +0:30, +0:20, +0:10, +0:00. The +1:00 before the line is a reminder of the time token | G3–G5, BGG punchboard photos                | verified |
| D-018 | Specialist powers                  | Strong Ascents caps at 6 or 7 per card; some cards carry two powers                                                                                                     | G12                                         | verified |
| D-019 | Bonus tile                         | Tile #9 is a half-length tile with no special rule                                                                                                                      | P2, G16                                     | verified |
| D-020 | Muscle card                        | Value 5                                                                                                                                                                 | P1                                          | verified |
| D-021 | Placement turns                    | Each team places both its riders (either order), then the next team clockwise                                                                                           | B2 example (red, then black, then blue)     | verified |
| D-022 | Pack straddling an ascent          | Only the squares in front of the rearmost ascent rider move up; riders behind it stay                                                                                   | B4 mountains example                        | verified |
| D-023 | Moving past the end of the track   | Movement stops at the last square of the finish tile, then normal blocking applies                                                                                      | rulebooks silent                            | house    |
| D-024 | Dummy teams outside Peloton races  | Peloton and Muscle dummy teams may join any race; they need none of the Peloton tiles or rules                                                                          | P3 (dummies are self-contained)             | decided  |
| D-025 | Dummy decks running out            | A dummy deck that runs out is reshuffled from the cards it has flipped (Muscle riders keep flipped cards in their recycle pile)                                         | rulebook silent                             | house    |
| D-026 | Breakaway placement                | Winners go to the marked square of tile #2 (4th square), highest bid in lane 0; two winners with 5–6 teams, one otherwise and in one-rider-each                         | tile #2 marking; P2                         | house    |
| D-027 | Breakaway bid cards                | Winners' bid cards join their public history of revealed cards (so remaining decks stay derivable); losers' bids are recycled                                           | P2 (cards leave the game)                   | decided  |
| D-028 | Peloton terrain without the module | Cobblestone and supply rules follow the tiles: they apply whenever a stage has those squares                                                                            | P1                                          | decided  |
| D-029 | Colours in one-rider-each          | Two seats may share a colour when one rides its rouleur and the other its sprinteur                                                                                     | P4 (riders are picked from the shared pool) | decided  |
| D-030 | Standing up with a 2               | A crashed rider whose card counts 0 after the penalty stands up in place and takes the rightmost free lane of its square                                                | M2                                          | verified |
| D-031 | Crashed riders still race          | They keep their place in movement order, occupy their lane, take exhaustion normally and can be blocked again                                                           | M2, D-015                                   | decided  |
| D-032 | Dummy teams in tours               | Pace riders only: they race and finish but take no tokens, earn no Tour Points and are left out of every classification and jersey                                      | D-008                                       | decided  |
| D-033 | Leading with no points             | Green and polka dot, rest-day sprint and mountain leaders, and sprint and mountain bonuses need at least one point; yellow always has a holder                          | G6, G7 (silent on zero)                     | house    |
| D-034 | Placement after stage 1            | Every team places in order of Tour Points, fewest first; ties: the team whose best rider has the lower total time places later                                          | G3                                          | verified |
| D-035 | Tours of original stages           | The basic tour and the short tour are our own stage lists (C-002); every tour stage gets the wide finish                                                                | C-002, G9                                   | decided  |

## Engineering

| Id    | Topic                 | Decision                                                                                                                                            | Status                      |
| ----- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| E-001 | Lane numbering        | Lane 0 is the rightmost lane; negative lanes are the verge (Nimble)                                                                                 | decided                     |
| E-002 | Event privacy         | Every `GameEvent` is public; private data travels only in `GameView.own`                                                                            | decided                     |
| E-003 | Seed privacy          | The seed and RNG state never leave the server (they reveal deck order)                                                                              | decided                     |
| E-004 | Square ids            | `t{tile}.s{segment}.q{square}` (`.b{branch}` inside splits), via `squareIdOf`                                                                       | decided                     |
| E-005 | Square index          | Start-line square is 0, grid squares negative, finish square = `finishIndex`                                                                        | decided                     |
| E-006 | RNG                   | sfc32 seeded by xmur3, state stored in `GameState.rng`                                                                                              | decided                     |
| E-007 | TypeScript            | Pinned to 6.0.x: typescript-eslint does not support TS 7 yet                                                                                        | decided                     |
| E-008 | Remaining values      | `PublicRider.remainingValues` keys by value and includes exhaustion cards                                                                           | decided                     |
| E-009 | Rider choice action   | `chooseRider` serves both the energy phase (deal first) and breakaway bidding                                                                       | decided                     |
| E-010 | Slipstream hook       | `slipstreamEligible(ctx, role, square, riders)` is asked per square for giving and receiving                                                        | decided                     |
| E-011 | Event reducer         | Public effects are applied only through `core/reducer.ts`; private card moves are direct                                                            | decided                     |
| E-012 | Hosting and authority | Static client on GitHub Pages; the host's browser runs the authoritative game; guests connect over WebRTC (ADR-0001)                                | decided (owner, 2026-11-10) |
| E-013 | Weather on clients    | The host deals weather from the seeded RNG at race start; `GameView.weather` carries it and clients lay it on their compiled track (`applyWeather`) | decided                     |
